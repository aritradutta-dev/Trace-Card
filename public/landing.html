The Problem

The build is red.
Where is the bug?

Developers scroll through thousands of log lines to find one real error, then guess whether it is a bug, a flaky test, or a broken config. Chatbots can explain errors, but they only see what you paste, never test their fix, and forget everything.

Noise buries the cause

Framework boilerplate, dependency downloads, and runtime warnings flood logs, drowning the single line that matters.

Fixes are guessed, not proven

Standard LLMs hallucinate obsolete imports or syntactically invalid patches because they have zero feedback loop.

Nothing is remembered

Every time a recurrent flake or missing env occurs across team branches, developers debug it from scratch all over again.

Architectural Advantage

What makes it different

Other tools explain CI failures. Trace-Card verifies the fix on the runner and remembers it.

Verified fixes

The patch is applied on the runner and the failing command is re-run. Only passing fixes get the Verified badge.

Error memory

Confirmed fixes are fingerprinted and saved. The next time the same error appears, the answer is instant and needs no model call.

Safe by design

Logs are trimmed and secrets are masked before anything leaves the runner. Nothing is pushed to your branch automatically.

Quick Setup

Add it to any repo in minutes.

Three lightweight steps to enable verified AI diagnoses across your team's CI pipelines.

1

Copy the workflow file

Place the YAML workflow into your repository under .github/workflows/trace-card.yml

2

Add GEMINI_API_KEY

Save your Google Gemini API key as a GitHub Repository Secret.

3

Push a commit

If CI fails, a Trace Card automatically appears on your pull request with verified fixes.

.github/workflows/ci.yml 
name: CI
on: [pull_request]
permissions:
  contents: read
  pull-requests: write
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: npm test 2>&1 | tee test.log
      - name: Trace-Card
        if: failure()
        run: node trace-card.js test.log
        env:
          GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

* Note: Secrets are not available to pull requests from forks for security isolation.
